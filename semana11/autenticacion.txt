El login permite identificar a cada usuario antes de acceder a una aplicación. Gracias a la autenticación, solo las personas autorizadas pueden realizar determinadas acciones. Algunas rutas deben estar protegidas porque contienen información privada o funciones importantes del sistema. Esto ayuda a evitar accesos no autorizados y protege la información de la comunidad. No se deben publicar contraseñas, documentos de identidad, direcciones, teléfonos, tokens, claves de API ni otros datos sensibles.
