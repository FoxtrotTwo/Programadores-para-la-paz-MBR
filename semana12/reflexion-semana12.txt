Durante este curso aprendí que la tecnología puede ser una herramienta muy útil para fortalecer la participación ciudadana y la organización comunitaria. Comprendí cómo crear aplicaciones sencillas con Node.js y Express, trabajar con rutas, recibir información y organizar datos. También aprendí la importancia de proteger la información y aplicar buenas prácticas de seguridad digital. Conocí cómo las bases de datos, la automatización y herramientas como Telegram pueden facilitar el seguimiento de actividades comunitarias. Además, entendí la utilidad de Git y GitHub para controlar versiones y compartir proyectos. Todos estos conocimientos permiten desarrollar soluciones tecnológicas más organizadas, seguras y útiles para apoyar el trabajo de las comunidades.
